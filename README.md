# Swift Networking

Swift Networking to learn how to use URLSession in iOS.
There are three tabs: Github, Picsum, and Download.
Github and Picsum fetch JSON with a data task and keep it in memory. Picsum uses URLComponents and URLRequest.
Download uses a download task to save the file to disk, with progress, pause, and resume.

## Tech stack

* Swift + UIKit
* URLSession
* URLComponents and URLRequest
* async/await
* Codable
* NWPathMonitor
* UITableView
